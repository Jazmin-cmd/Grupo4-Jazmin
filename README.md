# Demo Práctica JSON

Proyecto de demostración práctica utilizando HTML, CSS, JavaScript y PHP para explicar el funcionamiento de JSON en el desarrollo web.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- PHP

## Integrantes

- Jazmin Zorrilla (Lider)


## Descripción

El proyecto consiste en un formulario que:

1. Captura datos desde el frontend.
2. Convierte los datos a formato JSON.
3. Envía la información mediante JavaScript al backend PHP.
4. Procesa y devuelve una respuesta.
